# Sistem Manajemen Tugas Interaktif

Mahasiswa sering kali kesulitan mengelola dan melacak tenggat waktu tugas kuliah, jadwal harian, serta catatan penting secara efisien dalam satu platform yang praktis dan terintegrasi.

## 🚀 Cara Menjalankan
1. *Clone* atau *download* repository ini ke perangkat lokalmu.
2. Buka direktori proyek menggunakan teks editor (seperti VS Code).
3. Jalankan file **`index.html`** langsung di peramban web (*browser*), atau gunakan ekstensi **Live Server** di VS Code untuk pengalaman terbaik.
