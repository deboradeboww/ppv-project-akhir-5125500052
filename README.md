# Sistem Manajemen Tugas Interaktif

Aplikasi web manajemen tugas dan perencana akademik interaktif yang dirancang untuk memudahkan pengelolaan tugas kuliah, catatan cepat, dan jadwal harian secara efisien dan menyenangkan.

## 🚀 Fitur Utama
1. **Formulir Tugas Cerdas**: Input tugas lengkap dengan validasi dan dukungan tombol *Enter* di kolom manapun.
2. **Daftar Tugas & Progres Bar**: Pemantauan status tugas secara *real-time* disertai filter kategori mata kuliah dan status pengerjaan.
3. **Catatan Cepat (Sticky Notes)**: Catatan tempel dengan berbagai pilihan warna estetik dan fitur sematkan (*pin*).
4. **Jadwal Kuliah Interaktif**: Tabel jadwal harian yang dapat disesuaikan waktunya menggunakan pemilih jam (*time picker*).
5. **Navigasi Melayang & Mode Audio**: Desain *bottom navigation* modern serta tombol *Sound On/Off* untuk mengontrol efek suara interaktif.
6. **100% Offline-Capable**: Seluruh aset gambar ilustrasi, efek suara, dan pustaka ikon FontAwesome tersimpan secara lokal.

## 🛠️ Teknologi yang Digunakan
*   **HTML5** (Struktur Semantik)
*   **CSS3** (Styling Modern, Variabel, Flexbox, dan Efek Glassmorphism)
*   **JavaScript (ES6+)** (DOM Manipulation & Interaktivitas)
*   **FontAwesome (v6.0.0)** (Ikon antarmuka lokal)
