# Roadmap Proyek - Sistem Manajemen Tugas Interaktif

Tabel rencana kerja dan tahapan pengembangan (*Sprint*) dari tahap awal hingga rencana pengembangan lanjutan:

| Tahap / Sprint | Fokus Pengembangan & Aktivitas Utama | Status |
| :--- | :--- | :--- |
| **Sprint 1** | Perancangan struktur dasar HTML, analisis kebutuhan pengguna, dan penyusunan tata letak layout utama. | Selesai |
| **Sprint 2** | Implementasi styling CSS (pembuatan variabel warna tema, tata letak kartu, dan desain responsif). | Selesai |
| **Sprint 3** | Pengembangan logika JavaScript inti untuk manajemen tugas, sistem filter kategori, dan bar progres. | Selesai |
| **Sprint 4** | Integrasi fitur *Sticky Notes* (dengan pilihan warna dan fitur pin) serta tabel jadwal kuliah. | Selesai |
| **Sprint 5** | Pembaruan UI/UX (navigasi bawah melayang), integrasi fitur *Sound Toggle*, dan modal edit data interaktif. | Selesai |
| **Sprint 6** | Pengujian fungsionalitas (*offline testing*), penyempurnaan tombol *Enter*, dan penyusunan dokumentasi proyek. | Selesai |
| **Sprint 7 (Future / v2.0)** | Rencana penambahan fitur penyimpanan permanen **`LocalStorage`** agar data tidak hilang saat *refresh*. | Perencanaan |
| **Sprint 8 (Future / v2.0)** | Pengembangan modul **Autentikasi / Login Page** di awal aplikasi untuk multi-pengguna. | Perencanaan |
| **Sprint 9 (Future / v2.0)** | Fitur **Kustomisasi Jadwal & Mata Kuliah** mandiri oleh *user* (pengaturan jadwal dinamis). | Perencanaan |
| **Sprint 10 (Future / v2.0)** | Penambahan fitur pendukung seperti **Dark Mode**, *Search Bar* tugas, dan filter prioritas tingkat lanjut. | Perencanaan |
